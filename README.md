## 📦 वेबसाईट डिप्लॉय कशी करायची (Deployment Options)

प्रोजेक्टचे प्रोडक्शन बिल्ड तयार करण्यासाठी:
```bash
npm run build
```
हे कमांड `dist/` नावाचे फोल्डर तयार करेल ज्यामध्ये सर्व स्टॅटिक HTML, CSS आणि JS फाईल्स असतात.

हे फोल्डर तुम्ही विनामूल्य खालील प्लॅटफॉर्मवर थेट अपलोड करू शकता:
1. **Vercel** (`vercel deploy` किंवा GitHub द्वारे)
2. **Netlify** (`dist` फोल्डर ड्रॅग आणि ड्रॉप करा)
3. **Cloudflare Pages** (अतिशय जलद व मोफत)
4. **Hostinger / cPanel / Shared Hosting** (`dist` मधील फाईल्स `public_html` मध्ये कॉपी करा)
